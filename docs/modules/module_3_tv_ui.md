# 模块三：TV 桌面主页与媒体库界面模块 (TV Home & Library UI)

本模块采用 **Jetpack Compose TV (`androidx.tv.compose`)** 框架构建，严格遵循 Google Android TV 官方设计指南与 premium 视觉风格。模块重点在于提供**丝滑的遥控器焦点缩放、高斯模糊沉浸背景、清晰的 4K ISO 角标**以及**符合直觉的 D-Pad 导航逻辑**。

---

## 1. 核心页面结构与布局设计

### 1.1 侧边栏抽屉导航组件 (`TVNavigationDrawer`)
* **视觉状态**：
  * **收起状态 (Collapsed)**：宽度为 `80dp`，仅显示功能图标（主页、电影、电视剧、文件夹、设置）。背景为半透明磨砂玻璃（Glassmorphism）。
  * **展开状态 (Expanded)**：宽度为 `240dp`，当用户焦点左移到侧边栏或遥控器在最左侧内容按 Left 键时，侧边栏向右滑动平滑展开，显示文字标签。
* **对焦转换逻辑**：
  在 Compose TV 中，使用 `NavigationDrawer` 或 `TabRow` 配合 `FocusRequester` 来捕获和流转焦点。侧边栏处于展开状态时，焦点在导航项上，按 Right 键可将焦点归还给内容区的先前对焦组件，侧边栏在 `300ms` 内平滑收回。

---

### 1.2 沉浸式主页 (`HomeScreen`)
主页布局基于垂直滚动列表设计，顶部是一个大面积的**精选影片横幅 (Featured Hero Banner)**，下方是横向滚动的**继续观看 (Continue Watching)** 卡片流。

```
+-------------------------------------------------------------+
|  [Logo]                       [Search] [Notification] [User]|
|                                                             |
|   4K HDR REMUX   JUST ADDED                                 |
|   Dune: Part Two                                            |
|   ★ 8.8  2024  2h 46m  Sci-Fi, Adventure                    |
|   Paul Atreides unites with Chani and the Fremen...         |
|   [▶ Play Movie]   [ⓘ More Info]                            |
|                                                             |
|   Continue Watching                                         |
|   +-----------------------+   +-----------------------+     |
|   | Blade Runner 2049     |   | The Lord of the Rings |     |
|   | [=============------] |   | [==========---------] |     |
|   +-----------------------+   +-----------------------+     |
+-------------------------------------------------------------+
```

* **Featured Hero Banner**：
  * 使用海报背景图占满右侧区域，底部与左侧覆盖双向黑色渐变蒙层（Radial/Linear Scrim），保证文本和按钮的对比度。
  * 精选的电影卡片对焦时，背景海报会平滑渐变切换。
* **Continue Watching Shelf**：
  * 使用 `TvLazyRow` 容器。
  * 卡片底部包含一个进度条指示器（进度比率为 `currentTicks / totalTicks`）。
  * 卡片在对焦时发生微弱缩放（Scale `1.05x`），并且卡片边缘带有发光的蓝色阴影（Glow Effect）。

---

### 1.3 电影库海报墙 (`MoviesLibraryScreen`)
展示所有已同步电影的网格视图，具备高端海报设计和格式角标。

* **网格规格**：标准 1080p TV 屏幕下采用 **6 列纵向网格**，使用 `TvLazyVerticalGrid`。
* **格式角标设计**：
  * 电影海报卡片右上角叠加一个精美的半透明小药丸标记（Badges）。
  * 根据本地 Room 数据库的 `videoType` 与 `resolution` 字段动态渲染：
    * **`4K ISO`**：红金渐变小卡片。
    * **`1080p ISO`**：蓝银渐变小卡片。
    * **`1080p MKV`**：深灰半透明小卡片。
* **顶部对焦过滤器**：
  * 提供 `Genre（类型）`、`Year（年份）`、`Format: ISO/MKV（格式）` 三个过滤下拉按钮。
  * 当用户在海报第一排按 **Up 键**时，焦点移动至过滤器，按下 **OK 键**弹窗进行筛选。

---

### 1.4 电影详情页 (`MovieDetailsScreen`)
电影详情页是触发“光盘菜单播放”的起点，设计为双层深度沉浸视觉。

```
+-------------------------------------------------------------+
|   <- Back                                                   |
|                                                             |
|   Dune: Part One                                            |
|   2021 | PG-13 | 2h 35m | 4K UHD | HDR10 | Dolby Atmos      |
|   [▶ Play Movie]   [◎ Play with Disc Menu]                  |
|                                                             |
|   Chapters                                                  |
|   +---------+   +---------+   +---------+   +---------+     |
|   | Ch 1    |   | Ch 2    |   | Ch 3    |   | Ch 4    |     |
|   | 0:00:00 |   | 0:12:45 |   | 0:35:20 |   | 0:52:10 |     |
|   +---------+   +---------+   +---------+   +---------+     |
+-------------------------------------------------------------+
```

* **高斯模糊动态背景**：
  * 使用 Coil 异步加载当前电影的 `backdropUrl` 大图。
  * 通过 Compose 的 `Modifier.blur(25.dp)` 应用高斯模糊，再配合一层不透明度为 `0.6` 的黑色蒙版，形成富有空间立体感的背景。
* **双播放操作按钮**：
  * **「Play Movie（直接播放）」**：白色实心按钮，黑字，D-Pad 默认对焦它。点击直接略过光盘菜单，调用播放器核心定位到主影片直接开始。
  * **「Play with Disc Menu（光盘菜单播放）」**：黑色半透明描边按钮，白字。点击则启用 libVLC 引擎渲染光盘原生菜单（DVD）或原生 Compose 简易菜单（蓝光）。
* **章节轨道区 (Chapters List)**：
  * 展示横向缩略图卡片列表。点击某个章节，立即携带目标 Ticks 直接跳转到播放器，切入指定进度开始播放。

## 2. 遥控器焦点与交互优化规则

在 TV UI 交互中，最核心的原则是**“焦点必须可见、可控、防丢失”**。

1. **焦点指示器 (Glow & Border)**：
   * 所有可对焦组件（Button、Card、List Item）在对焦时，必须具有外边缘发光框（通常为 `#007AFF` 蓝色，粗细为 `2.dp`，外边距为 `4.dp`，避免裁切）。
   * 采用 HSL 调整机制：对焦时，卡片背景变亮，非对焦卡片不透明度设为 `0.7`。
2. **对焦记忆 (Focus Restorer)**：
   * 当用户从内容网格移到侧边栏导航，再移回内容网格时，内容区**必须**记忆上一次对焦的卡片位置，而不是重新定位到第一行第一个元素。
   * 使用 `androidx.compose.ui.focus.focusProperties` 中的 `enter` 和 `exit` 属性，配合 `FocusRequester` 链，精确保持历史焦点状态。
3. **滚动惯性与居中对焦**：
   * 在 `TvLazyRow` 中滚动时，被对焦的卡片最好始终保持在屏幕的**正中央**或**左侧 1/3 处**，为用户留出预期的视觉边缘空间，防止突然滚出屏幕。
